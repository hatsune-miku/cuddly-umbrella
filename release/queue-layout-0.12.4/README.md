# 0.12.4：构建队列布局与扩展缩放

2026-09-16 发布完成，保留经典 CakeUI。

- 工具栏、导航、筛选和分页不参与 flex 收缩，列表按内容高度内部滚动。
- 移除队列/记录卡片的左侧色条及 inset 阴影。
- 插件和主站 job-console 顶部左右圆角改为 0。
- 普通内容不可选中；输入框、命令、日志、分享链接和帮助文档仍可复制。
- 浏览器插件内容放大 1.2 倍，外框 672×600px，PC 嵌入式界面不缩放。
- 分支下拉定位将 viewport DOMRect 换算为 zoom 前坐标，避免缩放后的错位。
- 未修改后端、鉴权、构建和请求替换逻辑。
